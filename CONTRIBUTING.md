# Contributing / 参与开发

Issues and pull requests in English or Chinese are welcome. For bugs, include the GoWIN!Buddy version, Windows version, steps to reproduce, expected/actual behavior and a cropped screenshot if useful. Remove personal task names, machine paths and account data before posting logs or exported state.

Start with a focused change. Reproduce a bug where possible, verify the affected behavior, and run the relevant tests in [the build guide](docs/building.en.md). Keep personal data, compiled installers, node_modules and local runtimes out of commits. Do not add artwork unless it has a redistribution-compatible license and an attribution record.

Code, documentation and original art contributions are accepted under this repository's MIT license. Preserve upstream notices and third-party licenses.

欢迎使用中文或英文提交 Issue / PR。问题报告请提供版本、Windows 版本、复现步骤与实际结果；截图和日志先去掉个人任务、机器路径和账号信息。修改聚焦一个问题，验证相关行为，按[构建指南](docs/building.zh-CN.md)运行必要测试。不要提交个人存档、依赖目录、编译安装包或本机运行时。素材需有可再分发许可，并记录来源与署名。
