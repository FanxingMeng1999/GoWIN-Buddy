# GoWIN!Buddy v0.2.4 — Smoother mascot motion / 桌宠动作流畅度优化

The redesigned companions now move with clearer, softer motion at their compact desktop size. The SVG artwork stays sharp at any display density; this update improves animation travel, easing, preview cadence and state transitions.

![Smoothly animated lineup of ten desktop companions](https://raw.githubusercontent.com/FanxingMeng1999/GoWIN-Buddy/v0.2.4/docs/media/mascot-preview-v3.gif)

## English

- Increased the visible, eased travel in idle breathing, focused work, happy hops and resting motion while preserving the existing pet size and hitbox.
- Added a 140 ms opacity crossfade when the mascot changes state. Windows reduced-motion preferences keep state changes immediate.
- Re-rendered the ten-character overview and Rosy Crab close-up at 25 fps: 342 frames in a seamless 13.68-second loop.
- Preserved all ten distinct character silhouettes, vector scaling, eye tracking, click behavior, themes and window placement.
- Windows x64 installer: **GoWINBuddy-Setup-0.2.4.exe** (144,440,234 bytes; SHA-256 `908101F55C53103B201E487646159B1E20DBD25C0C45A95BAF473DDA55530B82`). The release includes `SHA256SUMS.txt` and detailed [verification results](https://github.com/FanxingMeng1999/GoWIN-Buddy/blob/main/docs/validation-0.2.4.md).
