# GoWIN!Buddy v0.2.3 — Natural mascot proportions / 桌宠自然比例重绘

The mascot artwork in v0.2.2 looked vertically compressed. This release redraws all ten characters with continuous rounded forms, soft material shading, expressive faces and articulated idle, work, happy and rest movements. SVGs, gallery tiles, promotional previews and transparent character PNG exports all use the same natural proportions. Runtime pet and hitbox geometry remain compatible.

![Ten naturally proportioned desktop companions](media/mascot-preview-v3.gif)

## English

- Ten distinct volumetric mascot shapes and transparent 384 px PNG exports.
- Looping idle, work, happy and rest animations, including crab-claw waves and animal tail, crest or limb movement.
- Uniform vector scaling removes the compressed appearance while retaining compact desktop sizing.
- Existing eye tracking, pet clicks, theme switching and window bounds remain in place.

## 简体中文

- 十种具有体积明暗和独立结构的桌宠，附透明底 384 像素 PNG。
- 待机、工作、开心与休息循环动作；螃蟹挥钳，狐狸、猫等角色摆尾，四肢与头饰轻轻活动。
- 全角色等比例缩放，消除被压扁的观感，同时保持紧凑桌面占位。
