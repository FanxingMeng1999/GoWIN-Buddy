# GoWIN!Buddy 开源发布文案

## 简短介绍

小芽 Sprout Buddy 来啦：一只陪你记待办、专注工作、积累进步的桌面宠物。鼠标移过去添加任务，双击打开本机 RPG 仪表盘；每天的小步推进，可以积累经验、星尘和里程碑。GoWIN!Buddy 提供独立 Windows 安装包、十种轮廓各异的原创角色和 MIT 开源源码。

## 完整介绍

GoWIN!Buddy 把桌面宠物和个人效率仪表盘放在一起。今日速勾随宠物展开，工作记录、每日签到、任务挑战、目标倒计时和反思记录在本机仪表盘中查看。桌宠和网页使用同一份本地存档，保存采用原子写入，保留上一份有效备份，并对并行修改进行合并或提示冲突。

这次公开版包含独立制作的小芽角色与提示音、中英文 README 和使用指南、基于锁文件的 Windows 构建脚本、实际录制的演示图片，以及附 SHA-256 的独立安装器。桌宠菜单跟随系统语言，仪表盘当前使用中文；安装包未进行代码签名，已内置运行时。
