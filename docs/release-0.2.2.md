# GoWIN!Buddy v0.2.2 — Compact companions / 紧凑桌面伙伴

GoWIN!Buddy v0.2.2 brings the pet back to a compact desktop footprint and adds ten genuinely different character silhouettes. Their idle, working, sleeping and reaction states keep the same desktop interactions.

## English

### What’s new

- A smaller, compactly composed pet that sits naturally beside your everyday work.
- Ten distinct forms: Sprout Buddy, Mossy Turtle, Midnight Penguin, Matcha Frog, Rosy Crab, Soda Fox, Paper Mushroom, Aurora Owl, Cocoa Cat and Pocket Robot. Each character has its own silhouette and details, rather than a palette-only variation.
- The complete set of animated states, theme colors, quick tasks and local RPG features remains available.
- Bilingual launch materials, guides and a character gallery are included with the source.

### Download and install

Download **GoWINBuddy-Setup-0.2.2.exe** from the [GitHub Release assets](https://github.com/FanxingMeng1999/GoWIN-Buddy/releases/tag/v0.2.2). The installer targets Windows 10/11 x64, installs for the current user and includes its runtime. The Release also provides `SHA256SUMS.txt` for verifying the installer. This build is unsigned.

For an upgrade, quit GoWIN!Buddy and run the new installer in the existing install folder. The app keeps its local save and preferences. See the [English guide](user-guide.en.md), [validation record](validation.md) and [third-party notices](../THIRD_PARTY_NOTICES.md).

## 简体中文

GoWIN!Buddy v0.2.2 将桌宠调整回更紧凑的桌面占位，并新增十种轮廓与细节各不相同的角色。角色在待机、工作、睡眠和互动状态下继续沿用现有桌面操作。

### 更新内容

- 缩小并收紧桌宠画面，让它更自然地陪伴日常工作。
- 十种不同形象：小芽、苔龟、午夜企鹅、抹茶蛙、蔷薇蟹、汽水狐狸、纸伞蘑菇、极光猫头鹰、可可猫和口袋机器人。每种角色都有独立轮廓和细节，不只是替换配色。
- 保留完整动画状态、主题配色、速勾任务和本机 RPG 功能。
- 源码内附中英文宣发文案、使用指南和角色展示图。
