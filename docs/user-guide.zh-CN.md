# GoWIN!Buddy 0.2.3 使用说明

GoWIN!Buddy 将原创小芽桌宠、今日速勾与本机 RPG 仪表盘放在一起。发布的安装包适用于 Windows 10/11 x64，已内置 Node.js 和 Python。

## 安装与启动

从 GitHub Releases 下载 **GoWINBuddy-Setup-0.2.3.exe**，运行后选择简体中文或 English、安装位置并启动。安装面向当前用户；后续使用桌面或开始菜单快捷方式。此版本未进行代码签名，Release 同时提供安装包的 SHA-256。

## 常用操作

| 操作 | 效果 |
| --- | --- |
| 鼠标移到宠物上 | 展开今日速勾，移开后收起 |
| Ctrl+Alt+Q | 打开并固定今日速勾 |
| 拖动宠物 | 调整位置；靠近屏幕边缘可进入迷你模式 |
| 双击宠物 | 打开本机 RPG 仪表盘 |
| 右键或托盘菜单 | 切换主题、大小、休眠、静音、开机自启和退出 |
| 速勾面板添加任务 | 支持临时、每日、每周、长期任务；临时任务可设截止时间 |
| 上班 / 下班 | 记录工作时间，并与仪表盘同步 |

桌宠菜单会跟随系统语言，仪表盘当前使用中文。已完成的临时待办通过“收起”清理；这个操作本身不发放 RPG 奖励。经验和星尘由仪表盘的任务、签到和里程碑规则发放。

## 数据、备份与冲突

安装版状态保存在 **%APPDATA%\gowin-buddy-pet\state\game_state.json**，偏好设置位于同目录上一级的 **gowin-prefs.json**。仪表盘由本机回环地址提供，日常任务和 RPG 功能无需云账号。

两个窗口修改不同内容时会自动合并；同时修改同一字段时，仪表盘提示冲突并保留本地缓存，请先导出 JSON，再刷新查看最新状态。速勾保存失败会保留输入，方便重试。成功写入使用原子替换，并保留上一份有效状态 **game_state.json.bak**。损坏的原文件会保存为 **game_state.json.corrupt-时间戳**，有备份时优先恢复。

建议定期在仪表盘导出 JSON，另存一份备份。卸载保留个人存档，重装可继续使用。重复启动会显示已有宠物。若其他程序占用 Ctrl+Alt+Q，可用托盘菜单打开面板。

## 更新与开发

从托盘退出宠物，备份 JSON，再将新版本安装到原目录。公开安装包采用 Release 手动下载更新。

源码保留可选的编程助手 Hook 和终端联动，需自行配置对应工具。安装版验收覆盖桌宠、速勾、本机仪表盘和安装流程。构建方法见[中文构建说明](building.zh-CN.md)，英文使用说明见[User guide](user-guide.en.md)。许可证见[MIT](../LICENSE)与[第三方说明](../THIRD_PARTY_NOTICES.md)。
