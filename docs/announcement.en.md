# GoWIN!Buddy is open source

## Short introduction

Meet Sprout Buddy: a small desktop companion for tasks, focus and everyday progress. Hover to jot down a task, double-click to open your local RPG dashboard, and build up XP, stars and milestones as you go. GoWIN!Buddy ships a standalone Windows installer, ten original themes and MIT-licensed source.

## Longer introduction

GoWIN!Buddy brings a desktop pet and a personal productivity dashboard together. Quick tasks sit beside the pet; work records, check-ins, quests, goal countdowns and reflections live in a dashboard served on your own computer. Atomic saves, backups and conflict handling keep the two views connected.

The public release includes original Sprout Buddy artwork and tones, English/Chinese documentation, a lockfile-based Windows build procedure, actual demonstration images and an installer with published SHA-256. The desktop menus follow the system locale; the dashboard currently uses Chinese labels. The Windows installer is unsigned and bundles its runtimes.
